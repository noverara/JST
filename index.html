Modul 1

Konsep Dasar Klasifikasi JST

Klasifikasi dalam Jaringan Saraf Tiruan (JST) adalah proses pemetaan dari variabel masukan (*features*) ke variabel sasaran yang bersifat diskrit (*categories/classes*). Model dipelajari untuk memprediksi kategori mana yang paling sesuai dengan suatu data baru.

Klasifikasi Biner

Memisahkan data ke dalam dua kategori (contoh: $0$ atau $1$, Positif atau Negatif).
• Contoh: Deteksi Email Spam/Bukan Spam, Diagnosis Penyakit.

Klasifikasi Multi-Kelas

Memisahkan data ke dalam lebih dari dua kategori ($K > 2$).
• Contoh: Pengenalan Angka Tangan (0-9), Jenis Kendaraan.

Anatomi Neuron Buatan (Perceptron)

Model klasifikasi terkecil dalam JST menerima input $X$, mengalikannya dengan bobot $W$, menambahkan bias $b$, dan melewatkannya ke fungsi aktivasi:

1. Input & Bobot X • W Nilai fitur dikalikan dengan kekuatan koneksi (bobot).
2. Kombinasi Linear Z = W•X + b Penjumlahan terbobot ditambah nilai Bias ($b$).
3. Output Prediksi Y = f(Z) Fungsi Aktivasi memetakan nilai $Z$ ke label kelas.
Modul 2

Arsitektur & Fungsi Aktivasi

Fungsi aktivasi bertanggung jawab membawa non-linearitas ke dalam jaringan. Tanpa fungsi aktivasi, JST hanya berperan seperti persamaan linear biasa meskipun memiliki banyak *layer*.

Fungsi Aktivasi Utama pada Model Klasifikasi:

Fungsi Sigmoid Range: (0, 1)
f(z) = 1 / (1 + e-z)

Mengompres nilai input acak menjadi kisaran 0 hingga 1. Sangat umum digunakan pada layer output klasifikasi biner karena nilainya dapat diinterpretasikan secara langsung sebagai probabilitas.

Fungsi ReLU (Rectified Linear Unit) Range: [0, ∞)
f(z) = max(0, z)

Mengubah seluruh nilai negatif menjadi 0 dan membiarkan nilai positif tetap. Sangat efisien dan menjadi pilihan standar untuk hidden layers dalam JST modern.

Fungsi Softmax Σ Probabilitas = 1.0
f(z)i = ezi / Σ ezj

Digunakan pada layer output untuk klasifikasi multi-kelas. Mengubah vektor output menjadi distribusi probabilitas di mana total seluruh kelas berjumlah tepat 1.0.

Modul 3

Lab Simulasi: Decision Boundary

Atur slider bobot ($W_1, W_2$) dan bias ($b$) di bawah untuk mengamati bagaimana garis pemisah keputusan (*Decision Boundary*) bergerak memisahkan Kelas A (Biru) dan Kelas B (Merah).

Parameter Neuron

Bobot 1 (W1): 1.0
Bobot 2 (W2): -1.0
Bias (b): 0.0
Persamaan Garis Keputusan:
1.0X1 + (-1.0)X2 + 0.0 = 0
