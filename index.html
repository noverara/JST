Modul 1

Konsep Dasar Klasifikasi JST

Klasifikasi dalam pembelajaran mesin (*machine learning*) dan Jaringan Saraf Tiruan (JST) adalah proses mengelompokkan data ke dalam kategori atau kelas tertentu berdasarkan ciri-ciri (*features*) data tersebut.

Klasifikasi Biner

Memisahkan data menjadi dua kelas (misal: 0 atau 1, Ya atau Tidak).
Contoh: Memprediksi apakah email termasuk Spam/Bukan Spam, atau memprediksi kelulusan mahasiswa (Lulus/Gagal).

Klasifikasi Multi-Kelas

Memisahkan data ke dalam lebih dari dua kelas.
Contoh: Pengenalan citra angka buatan tangan ($0$ hingga $9$), atau mengklasifikasikan jenis penyakit tanaman berdasarkan daun.

Komponen Utama Neuron Klasifikasi

Sebuah neuron buatan (Perceptron) memproses data klasifikasi melalui 3 langkah matematis utama:

  • Fitur Input ($X$): Nilai variabel yang dimasukkan ke dalam model ($x_1, x_2, \dots, x_n$).
  • Kombinasi Linear ($Z$): Perkalian antara input dengan bobot ($W$) ditambah bias ($b$):
    $Z = \sum_{i=1}^{n} (w_i \cdot x_i) + b = w_1 x_1 + w_2 x_2 + b$
  • Fungsi Aktivasi ($\hat{y}$): Mengubah hasil linear $Z$ menjadi rentang nilai probabilitas atau kategori kelas target.
Modul 2

Arsitektur & Fungsi Aktivasi

Fungsi aktivasi berperan penting untuk memberikan sifat **non-linear** pada jaringan saraf, sehingga JST mampu mempelajari pola-pola rumit pada data.

Fungsi Aktivasi Populer untuk Klasifikasi:

Sigmoid

Persamaan: $\sigma(z) = \frac{1}{1 + e^{-z}}$

Mengompres output ke dalam rentang nilai 0 hingga 1. Sangat umum digunakan pada *layer output* untuk **klasifikasi biner** karena output dapat diinterpretasikan sebagai probabilitas.

ReLU

Persamaan: $f(z) = \max(0, z)$

Mengubah semua nilai negatif menjadi 0 dan mempertahankan nilai positif. Paling efisien dan umum digunakan pada **hidden layer** JST modern.

Softmax

Persamaan: $\sigma(z)_i = \frac{e^{z_i}}{\sum_{j} e^{z_j}}$

Digunakan pada layer output untuk **klasifikasi multi-kelas**. Menghasilkan distribusi probabilitas di mana total seluruh kelas bernilai 1.

Modul 3

Lab Simulasi: Decision Boundary

Ubah parameter Bobot ($W_1, W_2$) dan Bias ($b$) di bawah ini untuk melihat bagaimana garis pemisah (*Decision Boundary*) memisahkan sampel Kelas A (Biru) dan Kelas B (Merah).

Parameter Neuron

Bobot 1 ($W_1$): 1.0
Bobot 2 ($W_2$): -1.0
Bias ($b$): 0.0
Persamaan Batas Keputusan:
$W_1 X_1 + W_2 X_2 + b = 0$
